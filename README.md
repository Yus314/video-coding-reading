## 機械可読データ

- `papers.json`：論文レコード。書誌・版・役割・問い・前提・根拠。
- `relations.json`：確認した引用と推奨前提・対比。関係の種類を明示。
- `comparison-conditions.json`：確認条件と未確認項目。
- `search-log.json`：今回の検索経路と未実施範囲。
- `papers/`：論文ごとのMarkdownカード。
- `sources.json`：原文URL一覧。著作権への配慮から、第三者の論文本文・取得キャッシュは再配布しない。
